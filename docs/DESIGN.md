# CardBattleRPG 設計書 (v0.1)

ブラウザで動作するカードバトルRPG。PC・スマートフォン(縦持ち)両対応。
ビルド不要の素の HTML / CSS / JavaScript で構成し、`index.html` を開くだけで遊べる。

---

## 1. ゲームコンセプト

- モンスターを育てながらステージを攻略していく「育成 × カードバトル」。
- デッキに入っているモンスターは **1枚ごとに個体** であり、バトルで戦うほど経験値を得てレベルが上がる。
- 同じ「ヒノコン」でも Lv1 と Lv8 では HP・ワザの威力が違う。育てたカードでデッキを組むのが RPG 要素の中心。
- ステージ初回クリアで新しいモンスター(Lv1)を入手 → デッキ編成 → 次のステージへ。

## 2. 基本仕様(必須要件)

| 項目 | 仕様 |
|---|---|
| デッキ枚数 | 40枚ちょうど |
| カード種類 | モンスター / エネルギー |
| 初期手札 | 5枚 |
| 通常ドロー | ターン開始時に2枚 |
| 先攻1ターン目 | 1枚ドロー |
| 手札上限 | なし |
| 山札切れ | トラッシュをシャッフルして山札を再構築してからドロー |
| モンスター個体 | 固有ID(uid)・レベル・経験値を保持(セーブデータに永続化) |

## 3. カード

### 3.1 属性
| 属性 | アイコン | 弱点(この属性から受けるダメージ×1.5) |
|---|---|---|
| 火 | 🔥 | 水 |
| 水 | 💧 | 雷 |
| 雷 | ⚡ | 草 |
| 草 | 🌿 | 火 |

ワザのコストの「★(無色)」はどの属性のエネルギーでも支払える。

### 3.2 モンスターカード
- 種族データ(マスタ): 名前、属性、基本HP、HP成長、攻撃成長、にげるコスト、ワザ(最大2つ)
- 個体データ(セーブ): `uid`, `speciesId`, `level`(1〜20), `exp`
- レベル補正
  - 最大HP = 基本HP + HP成長 × (Lv − 1)
  - ワザ威力 = 基本威力 + 攻撃成長 × (Lv − 1) (威力0のワザは補正なし)
- ワザ効果(v0.1): 自分回復 / ドロー / 相手ベンチ全体ダメージ / 自分のエネルギーをトラッシュ

### 3.3 エネルギーカード
- 属性ごとの1種類のみ。個体管理はしない(デッキ内は属性ごとの枚数で管理)。
- 自分のターンに1回だけ、自分の場のモンスター1体に付けられる。

## 4. バトルルール

### 4.1 場
- **バトル場** 1体 + **ベンチ** 最大3体。
- 山札・トラッシュ・手札。

### 4.2 準備
1. 双方のデッキをシャッフルし5枚引く。
2. 手札にモンスターがいなければ、手札を戻して引き直し(マリガン)。
3. 手札からモンスター1体をバトル場に出す。
4. 先攻・後攻をランダムに決定。

### 4.3 ターンの流れ
1. **ドロー**: 2枚(先攻1ターン目は1枚)。山札が尽きたらトラッシュを山札に戻してシャッフル。
2. **メイン**(順不同・何度でも)
   - モンスターを出す(バトル場が空ならバトル場、そうでなければベンチ)
   - エネルギーを付ける(1ターン1回)
   - にげる(1ターン1回、にげるコスト分のエネルギーをトラッシュしてベンチと入れ替え)
3. **ワザ**: バトル場のモンスターがワザを1回使う → ターン終了。
   - 先攻1ターン目はワザを使えない(調整可能なバランス項目)。
4. ワザを使わずに「ターン終了」も可能。

### 4.4 きぜつと勝敗
- ダメージがHP以上になったモンスターはきぜつ → 付いていたエネルギーと一緒にトラッシュ。
- きぜつさせるたびに **KOポイント +1**。**3ポイント先取で勝利**。
- バトル場がきぜつしたら、ベンチから1体を選んでバトル場へ。
- 自分のターン開始時に場にも手札にもモンスターがいなければ **敗北**。
  (場が空で手札にモンスターがいる場合は、まずバトル場に出す必要がある)

## 5. 育成(RPG要素)

| 獲得条件 | 経験値 |
|---|---|
| 相手モンスターをきぜつさせた | 20 + 相手Lv × 5 (ワザを使ったモンスターに) |
| 場に出た(勝利) | +20 |
| 場に出た(敗北) | +8 |

- 次のレベルまでの必要経験値: `20 + 現在Lv × 20`、最大Lv20
- 経験値はバトル終了時にまとめて反映、リザルト画面でレベルアップ演出。

## 6. ステージ進行
- 6ステージ。前のステージをクリアすると次が解放。
- 敵デッキは固定構成(敵モンスターのLvはステージごとに上昇)。
- 初回クリア報酬: 報酬プールから新規モンスター1体(Lv1、新しいuid)。
- 2回目以降も経験値は獲得できる(育成周回)。

## 7. 画面構成

```
ホーム ─┬─ ステージ選択 → バトル → リザルト → ホーム
        └─ デッキ編成(所持モンスター一覧 / エネルギー枚数調整)
```

### 7.1 バトル画面(スマホ縦持ち基準・PCでは中央に最大幅で表示)
```
┌──────────────────────────┐
│ 敵名  KO●○○  山札 手札 トラッシュ │ ← 相手ステータス
│ [ベンチ][ベンチ][ベンチ]         │
│        [ バトル場 ]              │ ← 相手
│ ── ターン3 / あなたのターン ──── │ ← 状況表示・ログ(タップで全文)
│        [ バトル場 ]              │ ← 自分
│ [ベンチ][ベンチ][ベンチ]         │
│ KO○○○ 山札 トラッシュ [ターン終了] │
│ [手札][手札][手札][手札] →スクロール │
└──────────────────────────┘
```
- 操作はすべて「タップ → ボトムシート」で完結(ドラッグ不要、ホバー不要)。
  - 手札をタップ: カード詳細 + 「バトル場に出す / ベンチに出す」または「付ける先」の一覧
  - 場のモンスターをタップ: 詳細 + ワザ使用ボタン + にげるボタン
- タップ領域は最小44px、`100dvh` とセーフエリア対応、ダブルタップズーム抑止。

### 7.2 デッキ編成画面
- 上部に枚数カウンタ(40/40でないと保存不可)。
- エネルギーは属性ごとに ± ボタン。
- 所持モンスターをタップでデッキに出し入れ(Lv・EXPバー・uid表示)。

## 8. 技術構成

| パス | 役割 |
|---|---|
| `index.html` | エントリ。スクリプトを順に読み込む(ESモジュール不使用 → file:// でも動作) |
| `css/style.css` | 全スタイル(モバイルファースト) |
| `js/util.js` | 乱数・シャッフル・uid生成 |
| `js/data/cards.js` | 属性・モンスター種族マスタ |
| `js/data/stages.js` | ステージ・敵デッキ定義 |
| `js/save.js` | localStorage セーブ/ロード、初期データ |
| `js/monster.js` | 個体生成、レベル補正、経験値計算 |
| `js/battle.js` | バトルエンジン(UI非依存の状態とルール) |
| `js/ai.js` | 敵の思考 |
| `js/ui/*.js` | 各画面の描画 |
| `js/main.js` | 画面遷移 |

セーブデータ(`localStorage["cbrpg_save_v1"]`):
```json
{
  "version": 1,
  "monsters": [{ "uid": "m_xxx", "speciesId": "hinokon", "level": 3, "exp": 12 }],
  "deck": { "monsterUids": ["m_xxx"], "energy": { "fire": 12, "water": 12, "grass": 0, "thunder": 0 } },
  "clearedStages": ["s1"]
}
```
